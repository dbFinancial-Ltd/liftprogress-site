What's New

Every update to Lift Progress, newest first.

September 7, 2026
New
  • Volume Day toggle — mark a lift's work set as a lighter volume day and it suggests a weight as a percentage of your last normal-day session, rounded to plates you actually have on hand
  • Volume Day sets and reps can optionally auto-swap too, if you've set that up for a lift — leave it blank to only adjust weight
  • A "VOL" badge now shows on volume-day sets in the workout screen, the log, and the progress chart's tap-to-view day detail, so they're easy to spot at a glance
Fixed
  • The Well-Equipped and Home Gym microplate presets were missing some of the standard fractional plate weights — both now match a full 0.25–1 lb fractional set
September 5, 2026
New
  • Gym profiles — save your bars, plate inventory, and per-lift rack pin heights as a named profile, then switch between gyms in one tap without re-entering anything
  • Confirmation prompt before deleting a lift from a session, naming the exact lift so it's harder to remove the wrong one by mistake
  • Bigger, easier-to-tap buttons across the warm-up step controls and menus during editing
  • Bar inventory — track multiple bars of different weights and types, with an app-wide default and optional per-lift overrides
  • Warm-up steps can suggest switching to a better-fitting bar when it would mean fewer plates — always just a suggestion you choose whether to accept, never automatic
  • Onboarding now covers setting up your bar (including adding more than one) and lets you choose between automatic or manual weight progression up front
  • Settings reorganized — per-lift settings (sets/reps, progression increment, pin heights, bar) now live together in one place per lift instead of four separate lists
  • Belt reminder — mark a lift to show a "wear your belt" badge in the workout screen
  • Rack pin height now shown as color-coded badges instead of plain text, for a quicker glance mid-session
Fixed
  • Weight suggestions now correctly use your heaviest set from the most recent session when a lift has more than one work set (like a heavy set plus a backoff), instead of whichever set happened to be entered second
  • Resetting a lift's warm-up now correctly goes back to your default bar instead of keeping whatever bar was swapped to earlier in that session
  • Reordering work sets now updates the warm-up correctly once you finish editing, instead of only updating after a manual edit to the weight
  • A few edge cases around typing a lower weight after an earlier bar swap
  • A lift's bar could show up blank ("on bar") in a few situations — adding a second work set, reopening an older saved workout, or on certain lifts — now consistently shows correctly
  • Safety squat bars created before a recent naming update now correctly include "Safety Squat" in their name
September 4, 2026
New
  • Add multiple work sets per lift — a heavy set plus a backoff set, for example — each tracked and saved on its own
  • Reorder or rename warm-up steps and work sets to match how you actually want to work through a lift
  • Confirmation prompt before deleting a lift from a session, to avoid accidental deletions
Fixed
  • Custom warm-up steps now actually save with the workout — previously they only appeared for that session and were never stored
  • A lift with more than one saved set no longer shows a duplicated warm-up ladder when reopened
  • Weight suggestions for your next session now correctly use your heaviest set from last time when a lift had more than one work set
  • Plate breakdown for newly added custom warm-up steps now calculates correctly instead of showing "empty bar"
  • Easier-to-tap buttons throughout the workout editing screens
September 3, 2026
New
  • Guided setup on first launch — pick your bar weight and plate inventory in a couple taps instead of configuring everything by hand
  • Optional manual progression mode, for lifters who don't want weight auto-added every session
  • Rack pin height tracking, so you don't have to remember or recheck where you set the rack each session
  • Color-coded log — today's workout in red, completed in blue, planned in white, so it's easy to see what's next at a glance
  • Bulk import — bring in past workout history from a spreadsheet instead of entering it one session at a time
Fixed
  • Several iOS display issues at larger accessibility text sizes
  • iOS back-button and date-picker issues in the New Workout flow
  • Backdating an older workout out of order no longer produces a confusing weight suggestion
September 1, 2026
New
  • First testing build — workout logging, warm-up ladders, plate calculator, progress tracking, and rest timer
